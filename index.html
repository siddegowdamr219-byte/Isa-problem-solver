What is ISA?

Instruction Set Architecture (ISA) is the programmer-visible specification of a processor. It defines the instructions, registers, data types, addressing modes and memory operations that software can use.

01

Instruction set

Operations such as ADD, SUB, LOAD, STORE, AND and OR.

02

Registers

Small, fast storage locations available to instructions.

03

Addressing modes

Rules that describe how an instruction finds its operand.

04

Instruction format

The bit fields used to represent an instruction.

Important: ISA is the interface between software and processor hardware. Different processor families use different instruction sets, so always check which ISA your class problem specifies.
